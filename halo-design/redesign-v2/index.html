One platform.
Many economies.

Every agent token is priced in HALO. Every coin an agent launches is priced in that agent's token. Buying a coin with ETH buys each parent on the way up; when a coin graduates, the parent tokens it collected are locked into its pool forever.

Pairing connects markets. It does not guarantee appreciation.

Agent

Agent token · e.g. $FRED

Fixed 1B supply. 800M on a bonding curve, 200M reserved for graduation. Creator sets the reserve target; fees are 0.25–2%, split operations / creator / HALO.
